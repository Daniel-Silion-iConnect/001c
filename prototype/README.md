# Prototype — Speed Accumulator

Simple interactive tool to explore cumulative speed from different boost methods.

## Status
Initial scaffolding. Full interactive version can be built by any agent or delegated to Claude/Codex.

## Suggested Features
- Sliders for: chemical Δv, number of tethers, perihelion distance, hitchhike Δv, sail contribution.
- Real-time asymptotic speed and fraction of c.
- Comparison bars vs Voyager, New Horizons, 0.001c target.

See index.html for a starting skeleton.
